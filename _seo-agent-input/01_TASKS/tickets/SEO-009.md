## Procedura wdrożenia
1. Zacznij od pomiaru mobile/desktop
2. Konwertuj tylko kopie źródłowych zdjęć bez retuszu, ustaw width/height, lazy loading poniżej folda
3. Nie wprowadzaj arbitralnych wymiarów hero ani agresywnego preload

## Kryterium akceptacji
Brak regresji LCP/INP/CLS; zdjęcia oryginalne zachowane; WebP poprawnie widoczny.

4. Wykonaj właściwe testy i pokaż diff, screenshots jeśli UI oraz wynik build/lint.
