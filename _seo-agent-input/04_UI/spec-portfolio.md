# Wizualizacja: portfolio i case study

## Karta portfolio
- Proporcje zdjęcia 4:3 lub 3:2 (zachowaj oryginalny kadr bez agresywnego crop), alt opisuje faktyczny widoczny przedmiot.
- Dla RÅSKOG tytuł „Odbojnik do wózka RÅSKOG – projekt TPU”, 1 zdanie o analizie mocowania + badge "Projekt własny"; nie deklaruj produkcji seryjnej, jeśli niepotwierdzona.
- Cała karta jest linkiem /realizacje/odbojnik-ikea-raskog/; spójne focus states.
- Na obecnym etapie **TYLKO 1 prawdziwy projekt**. Nie dawaj dwóch sztucznych "przyszła realizacja" kart w publicznej sekcji. Jeżeli samotna karta źle wygląda, zrób szeroką featured-card.
- Kolejne karty dopiero z rzeczywistymi zdjęciami i dokumentacją. Nie używaj grafik AI z `07_REFERENCJE`.

## Case study
Hero: tytuł + krótki lead + dokumentacyjne foto; niżej: Problem / Materiał / CAD i iteracje / Efekt i ograniczenia / Galeria rzeczywistych zdjęć / CTA.

## Assety
Referencje mają manifest z oryginalnymi nazwami. Zdjęcia z poprzednich przesłań mogą zawierać składane plansze i ujęcia przed/po. Po weryfikacji oznaczaj jako "materiał produktowy", "zdjęcie montażu" albo "wizualizacja" adekwatnie do treści. Nie używaj ich jako rzekomo nieprzetworzonych ujęć, jeśli zawierają tekst, strzałki lub kolaż.
